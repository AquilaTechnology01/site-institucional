# Contribuindo

Obrigado pelo interesse em contribuir com os projetos da Aquila Technology.

## Antes de contribuir

Leia toda a documentação do projeto.

Verifique se já existe uma Issue relacionada.

## Como contribuir

1. Faça um Fork do projeto.

2. Crie uma nova Branch.

```bash
git checkout -b minha-feature
```

3. Faça suas alterações.

4. Faça o commit.

```bash
git commit -m "Minha nova funcionalidade"
```

5. Envie para seu Fork.

```bash
git push origin minha-feature
```

6. Abra um Pull Request.

## Padrões

- Código organizado;
- Comentários apenas quando necessários;
- Seguir o padrão do projeto;
- Manter compatibilidade sempre que possível.

## Reportando problemas

Caso encontre algum bug, abra uma Issue contendo:

- descrição;
- passos para reproduzir;
- comportamento esperado;
- prints (quando possível).

Obrigado por contribuir com a Aquila Technology.
